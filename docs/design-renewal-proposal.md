## 1. 現状の振り返り（要約）

サイトは「白背景 + #333テキスト + 固定サイドバー + コンテンツ」の2カラム構成。
トップページは p5.js の立方体グリッドアニメーション（sketch_1.js）が唯一のビジュアルで、
コンテンツ領域は実質空。下層は sketch_3.js の縮小版キャンバスがサイドバー背後に置かれる。

**一言でいうと「研究室の個人ページ」の系譜。** 誠実で読みやすいが、
ADAA大賞受賞・VJ/DJ/サウンドエンジニアという経歴の熱量・音楽性・空間性が、
白地に細いゴシックの文書レイアウトからは伝わってこない。
「ミニマル」ではなく「未デザイン」に見えてしまっているのが核心的な課題。

### 残すべき資産

- **p5.js 立方体グリッド**: サイト唯一の署名的ビジュアル。捨てずに「昇格」させるべき
- **グリッチ/タイプライター演出**（works-spa.js）: クリエイティブコーダーらしさが出ている
- **3項目ナビ + 固定サイドバー**: 認知負荷が低く、迷いようがない骨格
- **ハッシュルーティング**: ブラウザバック・URL共有が正しく機能、フィルタ状態保持も丁寧
- **CSS変数のタイプスケール基盤**（common.css）: トークン差し替えでリデザイン可能な良い土台
- **モバイル配慮の要所**（44pxタッチターゲット、タッチ時オーバーレイ常時表示など）

## 3. リファレンスから抽出した設計原理

mount inc. と Rhizomatiks Design に共通する「面白さ」の正体:

1. **額縁は無彩色、色は作品が持つ** — サイトの色数を極限まで絞り、サムネイルが唯一の彩度源
2. **タイポグラフィを「システム」として設計** — 数値タイプスケール、欧文グロテスク+和文ゴシック、ラベルに広い字間（0.08em）
3. **メタデータが装飾になる** — 日付・カテゴリ・クレジットを几帳面なフォーマットで見せること自体がデザイン。「記録性 = 誠実さ = エンジニアリング感」
4. **ジェネラティブ要素は一点豪華主義** — 全面に散らさず1箇所に凝縮し、残りは静的で精密（Rhizomatiksはロゴ背後のCanvasのみ）
5. **ホバー文法の完全な一貫性** — 全リンクが同じホバー言語・同じ200ms。テンプレ感の正体は「ホバーの不統一」
6. **技術の気配を細部に残す** — コード風命名（`_code` `for_Experiment`）、等幅数字の日付、最新Web API

**特に参考になる実例**: daito.ws（真鍋大度の個人サイト）。IBM Plex Mono / Plex Sans / Plex Sans JP だけで組んだビルドなし静的サイト。フォントとフォーマットの規律だけで「エンジニアの個人サイト」の格を出している。本サイトと同じ制約条件（GitHub Pages・ビルドなし）での成功例。

## 4. リデザインの方向性

### 推奨コンセプト: 「Boxグリッドをブランドに昇格 × レコード型ポートフォリオ」

方向性A（Boxグリッドのブランドシステム化）を軸に、リファレンスの原理（モノクローム規律・メタデータのレコード化・一点豪華主義）を重ねる。

- **色**: 白/黒のモノクローム基調をCSS変数で厳密化。アクセントは1色に統一（現行 #006DD9 を正式採用 or 蛍光系 #00FF66 でクラブ感）。#B20000 / #FF7043 は廃止
- **書体**: IBM Plex Sans + Plex Sans JP + **Plex Mono**（Google Fonts、セルフホスト可）。日付・カテゴリ・メタデータは Mono で組み、既存グリッチ演出と世界観を接続
- **p5.js**: sketch_1 にマウス反応を追加して「触れる名刺」化。sketch_3 は廃止し、モチーフを装飾部品（区切り線、ロゴ背後の帯）として再配置
- **Works**: 各サムネに `タイトル / 年 / _category` の定型メタデータ行を常時表示（レコード化）。代表作2件は2倍幅セルでヒエラルキー
- **カテゴリ表記**: `_code` `_object` `_design` とアンダースコア命名でコードの語彙をUI言語に

### 段階導入ロードマップ

#### Phase 1: クイックウィン（低リスク・効果大、1セッション規模）

1. **トップに最小限の一言と一手**: 肩書き1行（Aboutに既存の "Creative Technologist / Artist / Researcher"）+ "Works →" リンクだけ置く（U1/D1）
2. **sketch_1.js にマウス反応**: カーソル近傍のboxだけ持ち上がる/回転が変わる（distベース数行）。「背景が自分の入力に反応した」という発見は最も安価で雄弁な自己紹介
3. **Worksグリッドのラベル常時表示**: 既存 ::after を opacity:1 にするだけ（U3）
4. **アクセント1色に統一**: 全CSS内の色をCSS変数化して #006DD9 に集約（D2）
5. **現在地表示を `<s>` → アクセント色+bold+aria-current に**（U6）
6. **Contact を mailto: 化**: JSで組み立て+Copyボタン（スパム対策両立）（U4）
7. **prefers-reduced-motion 対応 + インライン opacity:0 廃止**（U5）
8. **迷子ページの整理**: blanc.html / ZigSow copy.html 等の削除 or noindex（U7）

#### Phase 2: デザインシステム再構築（中規模、2〜3セッション）

1. **フォント導入**: IBM Plex ファミリー（メタデータ=Mono、本文=Sans/Sans JP）
2. **タイプスケール拡大**: h1 28px → 48〜64px、ジャンプ率を上げて見せ場を作る。hr全廃 → 余白+小ラベル（12px・letter-spacing 0.15em・大文字）でセクション区切り
3. **ホバー文法の統一**: サムネ=オーバーレイスライドイン（opacity 0.6廃止）、テキストリンク=下線スライド、全て200ms
4. **回遊ナビ再設計（issue #19の解決）**:
   - ヘッダーをブレッドクラム化: `Works / 作品名`（既存グリッチ演出が「Worksの下層」というナビ情報になる。枠線ボタン不要 = 初回却下理由を根本解消）
   - Prev / Next ナビ（index.json の worksOrder 活用、フィルタ尊重、矢印キー対応）
   - 本文末尾に「Other Works」サムネ帯（同カテゴリ3〜4件）
   - 旧静的ページ works/*.html → works.html#id へ meta refresh リダイレクト
5. **サイドバー刷新**: br区切り → li化、"This is..." 削除検討、ロゴタイプ設計
6. **Aboutのタイムライン化**: border-left の年号ライン + ADAA大賞にアクセントマーカー（テキスト内容は不変更）
7. **スクロールリビール**: IntersectionObserver 20行で inview フェードイン

#### Phase 3: 差別化の大玉（要判断）

- **ダークモード**: p5背景を黒地+白ワイヤーフレームに反転するだけで「オーディオビジュアル」の文脈になる。まず prefers-color-scheme での追加から段階導入
- **View Transitions API**: CSS 1行（`@view-transition { navigation: auto; }`）でページ遷移フェード。過去に失敗したページ遷移演出（Session 07の白フリッカー問題）の現代的な解
- **ショーリール**: mount式に代表作映像のリールをトップに（映像制作が必要）

## 5. 制約事項の確認

- 作品のタイトル・説明文・クレジット等のコンテンツは**一切変更しない**（CLAUDE.md保護対象）。上記は全て「見せ方（CSS/レイアウト/演出）」のみの提案
- ビルドプロセスなしの制約は維持可能（全提案が素のHTML/CSS/JSで実現可能）
- 過去の教訓: float レイアウトはCSS変更に脆弱（Session 03/04で2回破壊）。Phase 2 のレイアウト変更時はページ単位で段階適用+都度ブラウザ確認が必須
